# سیستم طراحی زنگ‌یار

## توکن‌های رنگ

| توکن | مقدار | کاربرد |
|---|---|---|
| `primary` | `#173B57` | هویت، تیتر، اقدام اصلی |
| `secondary` | `#159A91` | لینک، تأکید، وضعیت اطلاعاتی |
| `accent` | `#F4A340` | یادآوری و توجه |
| `background` / `paper` | `#F4F1E9` | پس‌زمینه‌ی گرم |
| `surface` | `#FFFEFA` | سطح خوانا روی کاغذ |
| `sage` | `#E3EAE7` | سطح ثانویه و ناحیه‌ی کم‌تأکید |
| `foreground` | `#282F36` | متن اصلی |
| `muted` | `#687680` | متن توضیحی |
| `border` | `#D8E1DF` | مرز کم‌کنتراست |
| `success` | `#25875F` | حاضر، موفق |
| `warning` | `#D4942E` | تأخیر، نیازمند توجه |
| `danger` | `#C94D4D` | غیبت، خطا |

توکن‌ها در `src/app/globals.css` تعریف شده‌اند و کامپوننت‌ها باید از کلاس‌های معنایی Tailwind استفاده کنند.

## تایپوگرافی

- فونت اصلی: Vazirmatn با `next/font/google`.
- تیتر صفحه: `text-2xl` تا `text-3xl`، وزن سنگین، خط‌ارتفاع باز.
- تیتر بخش: `text-lg`، وزن سنگین.
- متن بدنه: `text-sm`، خط‌ارتفاع ۶ تا ۸.
- متن کمکی: `text-xs` با رنگ `muted`.
- آمار و کدها: `tabular-nums`.

## شکل و فاصله

- شعاع پایه: `rounded-xl` برای کنترل‌ها؛ `rounded-2xl` برای پنل‌های اصلی.
- مرزها نازک و کم‌تأکید؛ از سایه فقط برای جداکردن سطح استفاده می‌شود.
- فاصله‌های اصلی: ۴، ۵، ۶، ۸؛ با `gap` و padding منطقی.
- کنترل‌ها حداقل ارتفاع ۴۴ پیکسل دارند.

## وضعیت‌ها

وضعیت فقط با رنگ منتقل نمی‌شود: نشانگر رنگی همراه با متن فارسی و در صورت نیاز آیکن/حرف کوتاه نمایش داده می‌شود. حالت‌های حضور عبارت‌اند از حاضر، غایب، تأخیر و موجه.

## نمودار و شاخص حضور

برای خلاصه‌ی امروز از نوار ترکیبی استفاده شده است؛ این فرم برای سهم چهار وضعیت از کل دانش‌آموزان مناسب‌تر از نمودار تزئینی است. هر بخش برچسب متنی جدا دارد، نوار `role="img"` و توضیح دارد، و نرخ حضور به‌صورت عدد برجسته نمایش داده می‌شود. در صورت اضافه‌شدن داده‌ی زمانی، نمودار خطی تک‌محوره با جدول جایگزین/همراه لازم است.
