# راهنمای RTL

- ریشه‌ی برنامه `lang="fa" dir="rtl"` دارد.
- برای فاصله و جای‌گذاری از `gap` و کلاس‌های منطقی مانند `border-e`, `ps`, `pe`, `inset-inline-end` استفاده می‌شود.
- متن فارسی `text-start` است؛ اعداد با `tabular-nums` و در کنار برچسب فارسی نمایش داده می‌شوند.
- نوار کناری در RTL در سمت راست قرار می‌گیرد؛ ترتیب گروه‌ها از نمای کلی به عملیات روزانه است.
- آیکن‌های جهت‌دار فقط وقتی معنا جهت دارد، باید mirror شوند.
- جدول دانش‌آموزان در موبایل با overflow افقی حفظ می‌شود.
- خلاصه‌ی حضور از نسبت‌ها استفاده می‌کند؛ ترتیب نوار از وضعیت‌ها پیروی می‌کند و برچسب جداگانه دارد.
- برای توسعه‌ی LTR، از `margin-inline`, `padding-inline`, `inset-inline` و `border-inline` استفاده شود و از `left/right` در layout پرهیز شود.
- تاریخ کسب‌وکار حضور باید از timezone مدرسه بیاید؛ اعداد نمایشی فارسی می‌توانند در UI باشند، اما داده‌ی ذخیره‌شده نباید با متن نمایشی جایگزین شود.
