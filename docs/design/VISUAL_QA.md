# چک‌لیست QA بصری

## اندازه‌ها

- [ ] دسکتاپ حدود ۱۴۴۰ پیکسل: sidebar، hierarchy، تراکم جدول
- [ ] تبلت حدود ۷۶۸ پیکسل: wrap فرم‌ها و خوانایی جدول
- [ ] موبایل حدود ۳۹۰ پیکسل: header، خلاصه حضور، کنترل‌های چهارحالته، overflow جدول

## RTL و دسترسی

- [ ] `dir=rtl` و جای sidebar
- [ ] focus keyboard قابل‌مشاهده
- [ ] label و نام accessible برای کنترل‌ها
- [ ] وضعیت فقط با رنگ منتقل نمی‌شود
- [ ] reduced motion رعایت می‌شود
- [ ] کنتراست متن اصلی و رنگ‌های وضعیت بررسی شده

## تعامل

- [ ] لینک‌های فعال و غیرفعال از هم قابل تشخیص‌اند
- [ ] attendance: تغییر سریع، جست‌وجو، bulk action، خلاصه و success state
- [ ] اطلاعات نمونه با متن شفاف از داده‌ی سرور جدا شده
- [ ] empty/loading/error state پیش از اتصال backend اضافه شود

## وضعیت این مرحله

smoke test مسیرهای `/dashboard`, `/attendance`, `/students` با `corepack pnpm dev` و HTTP موفق شد. بررسی screenshot واقعی با browser driver در محیط فعلی در دسترس نبود؛ بنابراین QA تصویری پیکسلی/اسکرین‌شات ادعا نمی‌شود و باید پیش از انتشار با Playwright تکمیل شود.
